# Moses Mabhida Ticket Sample Code
My first ticket system - Durban, South Africa

This system sells tickets for events at Moses Mabhida Stadium.
It prints receipts for customers.

Features:
- Shows seats left
- Calculates total cost
- Creates receipt file with date
- Handles errors

How to run: python sithembiso.py
